# 제작 대행(A) — 가격표 + 학원별 조회수 리포트

## 결정
- 도입 방식: A. 제작 대행 (원장님이 파일을 보내면 내가 만들어 링크를 드림) — 2026-10-11
- 가격: 제안안으로 로컬 시안 → 사용자 확정 후 운영 배포 (확정 전 운영 공개 금지)
  - 건별 1권(30쪽 이하) 25,000원 / 베이직 월 20,000원(월 5권·월간 리포트) / 스탠다드 월 45,000원(월 20권·임베드 세팅·학원 로고)

## 구현 단계
1. 데이터: 플립북에 `client`(학원명) 필드 — 업로드 폼·설정 폼·API에서 입력, 비어 있으면 "미지정"
2. 조회 기록: 봇·미리보기(크롤러, 링크 미리보기) 조회는 기록하지 않음. `views`에 (flipbook_id, viewed_at) 인덱스
3. 집계(DB): 기간별 플립북 조회수, 일별 추이, 유입 경로(도메인), 기기(휴대폰/PC) — Mongo 통합 테스트
4. 관리자 화면
   - `/admin/stats` 운영 대시보드: 최근 30일 전체 조회·학원별 표·교재 순위·일별 추이·저장 공간
   - `/admin/stats/client?name=학원` 학원별 리포트: 기간 선택(이번 달/지난달/30일), 교재별 조회, 추이, 유입 경로, 기기 비율, 인쇄(PDF 저장) 버튼, 인쇄용 스타일
5. 퍼널 페이지 가격표 섹션 + Q&A 비용 답변 갱신
6. i18n(en/ko), 테스트, 문서

## 원칙
- 개인정보 없이 집계만 (IP 저장 안 함, user agent는 기기 구분에만)
- 리포트는 원장님께 그대로 보낼 수 있는 한 장짜리 문서 느낌 (종이 감성 유지)
