# 관리자 화면 UI — 종이·아날로그 감성

## 문제 (사용자 캡처)
- `+ 업로드` 버튼 글자가 안 보임: `.nav-links a`(회색)가 `.btn-primary`(흰색)를 우선순위로 덮음
- 썸네일 잘림: 16:9 슬라이드를 4:3 칸에 `object-fit: cover`로 맞춰 양옆이 잘림
- 썰렁함: 카드 3장 아래로 빈 회색 공간, 정보가 적음, 브랜드(READMASTER)와 무관한 보라색 기본 테마

## 컨셉: 책상 위 교재 묶음
퍼널 페이지와 같은 토큰을 쓰고, 관리자 화면은 "책상 위에 교재를 펼쳐 둔" 장면으로 표현한다.

| 이름 | 값 | 역할 |
|---|---|---|
| 책상 | #EEEBE4 + 종이 결 노이즈 | 배경 (카드가 종이로 보이게 하는 바탕) |
| 종이 | #FFFFFF | 카드·패널 |
| 볼펜 잉크 | #1C2B4B | 글자·주 버튼 |
| 연필 | #6A7180 | 보조 글 |
| 괘선 | #DCE4EE | 공책 줄, 구분선 |
| 형광펜 | #FFE34D | 완료 상태, 선택된 메뉴 |
| 빨간펜 | #D6453D | 오류, 위험 구역, 공책 여백선 |
| 마스킹테이프 | rgba(234,220,184,.8) | 카드 상단 테이프 (대담함은 여기 한 곳) |

- 글꼴: 제목 Gowun Batang, 본문 Pretendard (퍼널과 동일)
- 상태 배지: 알약 모양 대신 형광펜으로 칠한 글자 (완료=노랑, 오류=빨간펜 밑줄, 변환 중=연필)

## 화면별
- 대시보드: 카드 = 테이프 붙인 종이. 썸네일은 공책 줄 위에 잘리지 않게(contain) 올림. 아주 약간씩 기울어짐(±0.6°), 마우스를 올리면 바로 섬. 마지막 칸에 점선 "새 교재 올리기" 카드로 빈 공간을 쓸모 있게 채움. 제목 옆에 권 수.
- 업로드: 종이 한 장 위에 폴더 탭, 점선(자르는 선) 드롭존, 진행 단계는 공책 여백선.
- 상세: 섹션마다 종이 패널, 임베드 코드는 줄 공책 카드, 위험 구역은 빨간펜 점선.
- 로그인: 테이프 붙인 색인 카드.

## 원칙
- 장식은 테이프·종이 결·공책 줄 세 가지로 제한. 모두 "종이"라는 하나의 은유에서 나옴.
- 움직임은 마우스에 반응할 때만(카드가 펴짐). 움직임 줄이기 설정이면 기울기·전환 없음.
- 대비: 본문 4.5:1 이상. 형광펜 위 글자는 볼펜 잉크.
