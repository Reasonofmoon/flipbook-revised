# READMASTER 플립북 — 퍼널 메인 페이지

## 브리프
- 대상: 다른 학원 원장님·강사 (교재를 웹에 올리고 싶은 사람)
- 할 일: 카카오톡 채널 상담 신청
- 위치: flipbook-revised.fly.dev `/` (기존 /admin 리다이렉트 대체)
- 참고: nbbang-go.netlify.app/interview — 흑백 에디토리얼, Pretendard, 880px 단, 숫자 줄, 휴대폰 목업 + 번호 단계, Q&A, 인용, 표
- 추가 요청: GIF 적극 활용 → **실제 제품을 녹화한 GIF** (가짜 화면 없음)

## 디자인 토큰
| 이름 | 값 | 역할 |
|---|---|---|
| 종이 | #FFFFFF | 배경 (참고 사이트 유지, 크림색 회피) |
| 볼펜 잉크 | #1C2B4B | 본문·제목. 순흑 대신 교재에 쓰는 파란 볼펜 잉크 |
| 연필 | #6A7180 | 보조 글 |
| 괘선 | #E3E6EC | 구분선, 표 |
| 형광펜 | #FFE34D | 유일한 강조색. 형광펜 밑줄·카톡 CTA와 같은 계열 |
| 빨간펜 | #D6453D | GIF 캡션의 짧은 주석에만 (채점 표시) |

- 글꼴: 제목 Gowun Batang 700 (교과서 명조 느낌), 본문·UI Pretendard
- 정렬: 왼쪽 정렬 단일 단 760px 본문, GIF 그림은 1080px까지 넓게 튀어나옴

## 레이아웃
```
[nav]  READMASTER 플립북                    카카오톡 상담
[hero] 제목(명조, 2줄) / 한 줄 설명 / CTA
       ┌──────── 브라우저 프레임 ────────┐
       │  실제 책장 넘김 GIF (가장 큰 요소)  │
       └────────────────────────────────┘
[사실 줄] PPTX·PDF·구글 슬라이드 | 링크 1개 | 학생 설치 0 | 한글 깨짐 없음
[네 단계]  GIF 무대(왼)  |  ① 올리기 ② 변환 ③ 링크·임베드 ④ 학생이 넘겨 봄 (누르면 GIF 교체)
[Q&A]   원장님들이 먼저 묻는 것 — Q 굵게, 답 본문, 중간에 GIF 그림 2개(한글 검색, 블로그 임베드)
[정직한 안내] 공개 범위·저작권 (링크가 있으면 누구나 봄)
[CTA]   형광펜 띠 위 카카오톡 상담 버튼
[footer] 관리자 로그인 링크
```

## 원칙
- 대담함은 한 곳: 히어로의 실제 책장 넘김 GIF. 나머지는 조용한 에디토리얼.
- 형광펜은 "학생이 보게 될 부분"에만 칠한다. 제목의 단어 하나 강조 금지.
- 숫자 표시는 실제 순서(네 단계)에만.
- 지어낸 고객 수·후기·성과 수치 금지. 확인된 제품 사실만.
- 자동 재생 움직임은 GIF가 담당. CSS 등장 애니메이션은 넣지 않는다.

## 검토 (기본값 회피)
- 처음 떠올린 안: 크림 배경 + 명조 + 갈색 포인트 → AI 기본값 1번과 겹쳐서 흰 종이 + 볼펜 잉크 + 형광펜으로 변경.
- 숫자 4개 줄은 흔한 처리라 고민했지만, 참고 사이트의 핵심 장치이고 내용이 실제 사실이라 유지. 대신 큰 숫자 대신 짧은 문장으로.
- 대문자 라벨, 가운뎃점 메타, 버튼의 화살표 → 쓰지 않음.

## GIF 목록 (로컬 Docker에서 Playwright + 시스템 Chrome으로 녹화)
1. hero-flip: 샘플 교재 책장 넘김
2. step-upload: 관리자 업로드 → 진행 → 완료
3. step-share: 공유 창의 링크·임베드 코드
4. step-mobile: 휴대폰에서 학생이 넘겨 봄
5. qa-search: "핵심어휘" 검색 → 해당 페이지로 이동
6. qa-embed: 학원 블로그(가상)에 붙인 모습
